
# Facts Requiring Internal Confirmation

Do not state the following as universal facts unless they have been internally confirmed:

- Exact evaluation criteria
- Exact number of criteria
- Recognition category
- One winner per category
- Recognition timeline
- Deadlines
- Licensing prices
- Licensing package details
- Logo usage rights
- Reprint rights
- Gala or event rights
- NDA availability
- Confidentiality terms
- Data retention policy
- Editorial review rights
- Publication rights
- Subscriber or audience numbers
- Exact deliverables
- Whether licensing is always optional
- What happens publicly if licensing is declined

If unsure, say:

"I don't want to give you the wrong information. Let me confirm the exact details for this evaluation rather than guess."
